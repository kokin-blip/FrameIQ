# FrameIQ v0.1.3 — Reliable model installation and optional tutorial

Published as [FrameIQ v0.1.3](https://github.com/kokin-blip/FrameIQ/releases/tag/v0.1.3) for Apple Silicon, macOS 14 or newer. v0.1.2 is unchanged.

## Changes

- A model download succeeds only after checksum/graph verification, runtime validation, atomic activation, and the ready installation commit. Failures and cancellation remain on the original job. Successful results identify the installation UUID.
- Onboarding, Settings, subject selection, and presets share the same model registry. Catalog packs are recognized by canonical content/task/tensor/preprocessing fingerprints, regardless of installation UUID or display name.
- Downloaded packs blocked by the 15% memory reserve remain unavailable and show their reason. Refresh memory status and Retry validation preserve verified bytes; validation retry does not download again. Overlapping attempts are rejected.
- Setup returns to the workspace. Start tutorial is optional; completed/skipped tutorials stay dismissed. Replay tutorial in Settings explicitly starts at step one.
- Migration 011 records durable setup attempts and uses existing upgrade backups. Existing projects, selections, model UUIDs, preferences, and exact-frame references are preserved.
- Local model labels are clearer. Makeup presets recognize the catalog's YuNet face detector.

## Installation

Extract `FrameIQ-v0.1.3-macos-arm64.zip` and move `FrameIQ.app` into Applications after quitting the previous instance. This private prototype is ad-hoc signed and not Apple-notarized. Existing project data is retained. Checksums, dependency notices, corresponding third-party sources, and verification notes accompany the patch. No weights or credentials are bundled.

## Verification and limits

49 frontend tests, TypeScript and generated-contract checks pass. The Rust workspace regression suite, including lifecycle, controlled HTTPS, fingerprint and migration checks, passes. Five installed-worker SDR/PQ/HLG exports pass with development library paths removed. Production and isolated Mac builds verify their ad-hoc signatures.

The isolated Mac application downloaded all three actual pinned packs (17,779,986 bytes total), matching manifest sizes/checksums and passing downloader graph checks. Runtime validation correctly failed with the unchanged 3.60 GiB system reserve on this 24 GiB Mac; no incomplete model was marked installed. Native cached retry and the shared Settings recovery states were checked. Native setup, recovery and optional tutorial were reviewed at 1000×700 and the available 1440×889 size; exact 1440×960 remains display-limited. The user chose to prepare this patch with native model validation pending. Successful ready-model restart/dropdown checks and licensed-fixture face/person/pose inference are therefore pending.

Automatic presets remain experimental; compatibility does not establish accuracy. Windows, accelerator compatibility and broader model accuracy are separate gates. No shopping or product-identification feature is included. The model-free offline extractor remains available without models, keys, or internet access.
