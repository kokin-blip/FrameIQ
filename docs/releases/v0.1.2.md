# FrameIQ v0.1.2 — Model setup and workspace tutorial

Updated build for **Apple Silicon (M1 or newer), macOS 14 or newer**. No Intel Mac or Windows installer is included.

## Changes

- First-run model setup: choose the face, person, and body-pose packs; review purpose, sizes, source URLs, licenses, and checksums before downloading. All three total approximately 17.8 MB. Installed packs are preserved; downloads run sequentially with progress, cancellation, and retry of unfinished packs.
- Skip model setup to use the offline extractor immediately. Reopen setup from Settings → Local models or the empty person-detector control.
- A short, skippable tutorial operates in the real workspace: import a video, step/select exact frames, and open Export Studio. Completed setup/tutorial stay dismissed; replay the tutorial from General & shortcuts.
- **Selections now clear by default when opening another file or project.** Turn off “Clear selections when switching files or projects” in Settings → General & shortcuts to retain cross-source collections. App startup, same-project reopening, and jumping to an already-selected frame preserve selections. Source files and existing export plans are retained.
- Active automatic selection must finish or be cancelled before a clearing switch. Failed clears and cancelled import dialogs preserve the current file and collection.

## Install

Download `FrameIQ-v0.1.2-macos-arm64.zip`, extract it, and move `FrameIQ.app` into Applications. Quit the previous FrameIQ instance before replacing it. Existing projects are retained, and database upgrade backups remain available.

This private prototype is ad-hoc signed, **not Apple-notarized**. macOS may require the app-specific Open Anyway option in System Settings → Privacy & Security on first launch. Checksums, dependency notices, corresponding third-party sources, and packaged-worker smoke evidence accompany the release.

## Verification and limitations

43 frontend tests, TypeScript, generated contracts, the production Mac build, signature verification, archive integrity, and packaged-worker SDR/PQ/HLG smoke checks pass. Native Mac checks covered first-run/review/skip, tutorial import/stepping/selection/export navigation, default clearing, opt-out retention, and saved state after restart. Screens were reviewed at 1000×700 and the available 1440×889 size; exact 1440×960 and Windows desktop acceptance remain open.

Download-queue cancellation/retry is fixture-tested. This native onboarding pass did not download model packs; production downloads still use the existing HTTPS, checksum, graph, runtime, and memory validation. Automatic presets/tracking remain experimental and not accuracy-validated. Automatic hair, accessories, footwear, and Complete Look remain unavailable. Real-model resource evaluation, accelerators, and live cloud-provider authentication/generation remain separate gates.

Offline extraction requires no model, API key, or network connection. Cloud AI is optional and sends only explicitly reviewed/approved images; provider charges may apply. No weights or credentials are bundled. Shopping, product identification, and lookbooks are not included. Full Dolby Vision dynamic metadata remains unsupported.

FrameIQ has no selected public source-code license. Third-party licenses apply independently.
