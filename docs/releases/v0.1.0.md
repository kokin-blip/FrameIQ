# FrameIQ v0.1.0 — First macOS release

First desktop release for **Apple Silicon (M1 or newer), macOS 14 or newer**. No Intel Mac or Windows build is included.

## Included

- Local video import, project creation/reopening, and source switching.
- Indexed exact-frame stepping, timestamp navigation, timeline thumbnails, precision wheel, and zoom/pan.
- Cross-source frame selections; PNG, JPEG, and WebP export with provenance sidecars.
- Missing-source relocation and interrupted export recovery.
- Explicit SDR/HDR conversion policies and supported 16-bit PNG exports.
- Quality recommendations, comparison, local model management, and opt-in experimental tracking for makeup, outfit/body, and custom regions.

The offline extractor works without model downloads, API keys, or an internet connection. No model weights are bundled.

## Install

1. Download `FrameIQ-v0.1.0-macos-arm64.zip` and extract it.
2. Move `FrameIQ.app` into Applications.
3. Launch FrameIQ. This private prototype build is ad-hoc signed and **not Apple-notarized**. macOS may block its first launch; use the app-specific Open Anyway option in System Settings → Privacy & Security if shown.

`SHA256SUMS.txt` contains asset checksums. The corresponding third-party source archive and dependency notices accompany this release; they are not needed to run the app.

## Current limitations

- Automatic tracking/preset results are experimental and not validated for accuracy. Hair, accessories, footwear, and Complete Look automatic execution remain unavailable. Guided regions remain supported.
- Completed real-model soak testing remains pending: the local release smoke's inference validation was refused by the configured memory reserve. The reserve remains enforced.
- Exact 1440×960 and 1000×700 native visual acceptance, clean Windows 11 desktop acceptance, and accelerator validation remain open.
- Full Dolby Vision dynamic-metadata preservation is unsupported. HDR metadata rendering varies across image viewers.
- AI shopping, product identification, and lookbooks are not included.
