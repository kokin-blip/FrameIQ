# FrameIQ v0.1.1 — Selections, cloud AI, and usability

Updated Mac build for **Apple Silicon (M1 or newer), macOS 14 or newer**. No Intel Mac or Windows installer is included.

## Changes

- Presets now live in Selections, with automatic addition of successful results and preservation of manually selected frames.
- Add/remove current frame, per-row removal, Select all for the current source, and Remove all for the project. Large collections are paginated.
- Project search, name/recent sorting, project renaming, source display aliases, and recorded last-opened times.
- Explicit Fit and actual-pixel 1:1 zoom; expanded precision shows exact neighboring indexed frames.
- Collapsible technical metadata and ranking settings, persistent export action, and Advanced color controls.
- Settings organized into Local models, Cloud AI, and General & shortcuts. Experimental pinned model packs have an explicit review step.
- Optional OpenAI and Gemini API keys stored in OS credential storage. Explicit model listing, image/crop descriptions, and advisory frame rankings use reviewed images and user approval. Main-canvas crops can be drawn, moved, and resized.

Offline extraction needs no API key, downloaded model, or internet connection. Cloud services are optional, may charge the user's provider account, and receive only explicitly approved images. No model weights are bundled.

## Install

Download `FrameIQ-v0.1.1-macos-arm64.zip`, extract it, and move `FrameIQ.app` into Applications. Quit your previous FrameIQ instance before replacing it. Existing projects are retained; database upgrades include a backup.

This private prototype is ad-hoc signed, **not Apple-notarized**. macOS may require the app-specific Open Anyway option in System Settings → Privacy & Security on first launch. `SHA256SUMS.txt` lists asset checksums. Dependency notices and corresponding third-party sources accompany the release.

## Verification and limitations

34 frontend tests, TypeScript, generated contracts, the serial Rust regression/fault suite, production builds, and five packaged-worker SDR/PQ/HLG checks are recorded in the repository's verification reports. Native Mac checks covered exact navigation, selection controls, project reopening, crop drawing/moving/resizing, and compact layout at 1000×700. The available large native window was 1440×889; exact 1440×960 acceptance remains open.

Live OpenAI/Gemini key authentication and generation have not been exercised in this release's acceptance pass. Automatic presets/tracking remain experimental and not accuracy-validated; automatic hair, accessories, footwear, and Complete Look remain unavailable. Windows desktop acceptance, accelerator compatibility, and sustained real-model evaluation remain separate gates. Full Dolby Vision dynamic metadata is unsupported; HDR appearance varies by image viewer. Shopping, product identification, and lookbooks are not included.

FrameIQ has no selected public source-code license. Third-party licenses apply independently.
