# Evaluation inputs and release gates

Synthetic fixtures are generated by Rust fidelity tests from FFmpeg test patterns; no third-party photographs or private video is committed. Their identities and color policies are asserted against sequential reference decoding. They establish decoder/recovery correctness, not fashion or visibility accuracy.

The real evaluation corpus remains an explicit release blocker: obtain 30 permissioned clips and at least 300 annotated frames. Each record must include its license/consent reference, source SHA-256, subject/group ID, split, integer presentation ordinal, region annotations, quality preference and visibility labels. Keep private media outside Git. Split by video and subject before deriving samples. Do not count adjacent frames as separate independent identity evidence.

Suggested JSONL record:

```json
{"origin":"permissioned_real","videoId":"owned-001","sha256":"...","subjectGroup":"subject-01","license":"owned-with-participant-consent","consentRef":"local consent record","split":"held_out","ordinal":"12","qualityRelevance":3,"acceptableRecommendation":true,"regions":[],"duplicateGroup":null}
```

For each algorithm/model revision report human recommendation acceptance, NDCG@8 versus uniform and sharpness baselines, duplicate precision, visibility precision with abstention, and hair mask IoU. Publish sample counts and confidence intervals. Never replace absent human labels with heuristic scores.

Run the backend benchmark with:

`cargo run -p frameiq-application --bin benchmark -- <video> <absolute worker> <report.json>`

Record codec, resolution, GOP, hardware, cold/warm state, runtime, and acceleration. This harness measures import, seek/cache, analysis, and actual cached reranking; GUI p95 and process working-set gates require additional platform profiling.

## Annotation validation

Run `python3 tools/validate-corpus.py annotations.jsonl --media-root /absolute/private/corpus --report /absolute/report.json --require-minimum`.

Records additionally require `origin: "permissioned_real"`. `path` is a relative media path when file verification is enabled. The validator checks source SHA-256, canonical presentation ordinals, human quality/acceptability labels, normalized rectangles, duplicate annotations, consistent provenance, and subject/source leakage between `calibration` and `held_out`. Synthetic and numerical parity fixtures cannot populate the accuracy corpus.

Without `--require-minimum`, small valid annotation batches are accepted for incremental collection. With it, fewer than 30 unique source hashes or 300 unique annotated frames, or a missing split, fails the command. A passing report validates structure and minimum size, not legal permissions, category coverage, annotation agreement or accuracy. Review license and consent references separately. Run validator regressions with `python3 -m unittest discover -s tools -p test_validate_corpus.py`.

The benchmark accepts an optional sustained-iteration count after its three paths. Schema 2 reports sampled coordinator/descendant RSS, actual loop duration, cached-analysis cancellation outcome, and real cached feature count. `rank2000P95Ms` remains null when fewer than 2,000 measured frames exist. RSS is sampled every 50 ms, can count shared pages twice, and may miss short peaks. A short run is not evidence of sustained stability or native UI responsiveness.

## Initial public acquisition

`public-sources.json` records per-file source pages, revisions, licenses, attribution, source groups, reserved splits, original URLs, byte lengths and hashes. Two reviewed originals were acquired outside Git and matched published SHA-1/length and locally recorded SHA-256. They are only the start of the required 30-source corpus. A rendered commercial template was excluded. Review subject overlap before freezing splits; unknown shared subjects cannot be assumed independent.

`python3 tools/prepare-corpus.py tests/evaluation/public-sources.json /absolute/media/root /absolute/frameiq-worker /absolute/empty/output --count 10` builds a canonical index and exports exact unscaled PNG inputs. It writes a local contact sheet and JSONL drafts with **null human labels**. Drafts intentionally fail the accuracy validator until annotated. It does not infer visibility, regions, orientation, duplicates, quality, or ground truth. Keep output outside Git. A second human must review at least 20% and resolve disagreements.

Benchmark schema 3 adds one-second sampled process-tree CPU, RSS and descendant counts. The optional sixth argument requests minimum sustained seconds (0–7200); ordinary CI requests 600, manual `soak` dispatch requests 7200. This loop covers seeks and cached ranking, not full inference/import/export/reopening stress, handles, native UI or GPU acceptance. Zero memory sampling is rejected instead of reported as a pass.
